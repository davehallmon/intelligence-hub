# Intelligence Hub

A static, browser-independent dashboard for frequently used tools, research sources, publications, people, organizations, topics, products, models, and platforms.

## Features

- 356 curated destinations and watchlist links
- Global search across titles, domains, categories, and URLs
- Responsive accordion layout
- Favicons with preview-safe loading behavior
- Every bookmark opens in a new tab
- Static files only; no build step or server required

## Structure

- `index.html` — page shell
- `styles.css` — responsive dark UI
- `data-destinations-1.js` through `data-destinations-3.js` — 226 use/explore links
- `data-watchlists-1.js` and `data-watchlists-2.js` — 130 figures/topics/organizations/products links
- `app.js` — search, accordions, favicon behavior, keyboard shortcuts

## Privacy

The public edition intentionally replaces personalized workspace URLs and user-identifying destinations with generic service URLs.
